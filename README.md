# 研途宝 · 考研英语 & 考研政治双核备战平台

> 专为全国硕士研究生招生考试（考研公共课：考研英语、考研政治）打造的高效备考学习系统。

---

## 🌟 核心功能一览

### 🇬🇧 考研英语模块 (English Hub)
1. **核心高频词汇记忆系统 (SRS)**
   - 精选大纲与真题高频核心词汇。
   - 包含音标、英美真人发音（Web Speech API）、词根词缀助记、考研真题搭配、近义词与真题例句。
   - 支持掌握度标记、生词本一键收录与过滤复习。
2. **历年真题长难句精读实验室**
   - 考研英语一/英语二历年真题长难句多维分色语法树拆解（主干/修饰/从句层级分明）。
   - 用户试译互动输入区与官方权威高分参考译文对照。
   - 语法难点、考点深入剖析及句中生词精准注释。
3. **高分写作语料库**
   - 闪光替换词库：将普通词（think, important, bad）替换为学术高级词汇。
   - 大小作文（建议信/图画阐释三段论）黄金通用框架，支持一键复制到剪贴板。

### 🇨🇳 考研政治模块 (Politics Hub)
1. **真题与模拟题客观题题库**
   - 覆盖马原、毛中特/新时代思想、近代史纲要、思修与法基四大科目。
   - 支持单选题（选后即判）与多选题（防错防漏多选提交机制）。
   - 配备名师级详尽考点溯源与命题陷阱预警。
   - 做错题目自动沉淀至政治错题本。
2. **考点速记卡片 (Flashcards)**
   - 3D 翻转卡片式背诵，涵盖马原辩证法、认识论、新发展理念等核心考点。
3. **主观大题（34-38题）万能模板**
   - 马原分析题“三步走采分法”、毛中特/史纲答题公式与万能论述金句。

### 📊 学情监控与综合管理
- **考研倒计时仪表盘**：动态计算距离今年12月考研初试剩余天数。
- **每日打卡系统**：激励备考自律打卡与天数统计。
- **学情统计图表**：词汇掌握率进度条、政治刷题量与正确率。
- **错题本与生词本**：随时消灭错题、重点复习生词。
- **本地持久化存储**：无须配置数据库，所有做题与背词记录保存在浏览器 LocalStorage 中，数据安全不丢失。

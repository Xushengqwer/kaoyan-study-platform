# 研途宝 (YanHub) · 项目演进路线图 (Project Roadmap)

研途宝定位于为全国硕士研究生考生打造的高效、纯粹、无广告的一体化智能备考系统。以下为项目的阶段演进与长期规划：

---

## 阶段一：核心基石与全景题库 (当前已完成 ✔️)
- [x] **考研英语大纲 5,530 全量词库**：包含真题考频、历年真题考查次数徽章、Unit 1~111 单元刷词、即时检索与真人朗读。
- [x] **智能意群断句实验室 (Sense Group Chunking)**：长难句按语法意群切分，训练考生阅读不回读、抓取核心句法主干能力。
- [x] **全文章智能划词即查字典**：文章中大纲核心词自动高亮标注，点击任意单词瞬间唤起大纲释义浮窗，一键收藏生词。
- [x] **自定义长文导入工坊**：支持粘贴任意真题或外刊文本，自动分段排版、自动标记考纲词汇并生成意群断句。
- [x] **考研政治全科题库与考点全书**：覆盖马原、毛中特与新时代、史纲、思修单选/多选题库、3D速记卡与34-37题答题万能模板。
- [x] **静态化部署与离线存储**：GitHub Pages 自动化持续集成，全量进度本地存储。

---

## 阶段二：AI 原生智能化赋能 (规划中 🚀)
- [ ] **AI 英语作文智能评分与语法纠错**：接入大模型 API，支持上传小作文/大作文，自动按考研大纲档次打分（词汇丰富度、语法准确性、行文连贯性），并提供高阶词句替换润色建议。
- [ ] **AI 政治主观题采分点智能诊断**：输入个人自答草稿，AI 根据标准采分点进行对比分析，标记“漏踩的核心原理”与“材料结合套话”。
- [ ] **真题阅读长难句语法树可视化渲染**：利用 SVG 动态绘制复杂的树状句法结构。

---

## 阶段三：多端体验与 PWA 增强 (规划中 📱)
- [ ] **PWA (Progressive Web App) 支持**：支持在手机 Safari / Chrome 中“添加到主屏幕”，无需通过应用商店即可像原生独立 App 一样全屏打开，离线使用。
- [ ] **暗黑模式 / 纸质护眼模式**：针对夜间刷题或深度阅读，提供柔和的羊皮纸色调与深色模式切换。
- [ ] **真题文章音频伴读**：为阅读文章配置标准英音/美音段落磨耳朵音频。
- [ ] **云端多设备可选同步 (Cloud Sync)**：接入轻量级开源 Backend (如 Supabase / Cloudflare D1)，支持通过简单口令跨设备同步生词本与做题进度。
